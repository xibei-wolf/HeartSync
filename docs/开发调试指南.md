# 开发与调试指南

> 面向二次开发者：如何把项目跑起来、如何连真机、如何排查问题。
> 本文合并了原先分散的《模拟器操作手册》与《真机调试手册》，去掉了重复部分。

## 二、导入与运行

1. Android Studio → **Open** → 选择仓库根目录（**选根目录，不要进 `app`**）
2. 等待 Gradle Sync 完成（首次需下载依赖，3~8 分钟）
3. 确认 `local.properties` 已生成；未生成则手动创建：
   ```properties
   sdk.dir=C:/Android/Sdk   # 换成你自己的 SDK 路径
   ```
4. 连接设备后点 ▶️ Run

> **Windows 中文路径提示**：AGP 默认拒绝在非 ASCII 路径下构建。项目已在 `gradle.properties` 中加入 `android.overridePathCheck=true` 关闭该检查，中文路径下可直接构建。

## 三、跑模拟器

### 3.1 启动

**方式一 · Android Studio 图形界面**
`Tools → Device Manager` → 找到目标 AVD → 点 **▶**

**方式二 · 命令行**
```bash
cd $ANDROID_HOME/emulator
./emulator.exe -avd <你的AVD名> -gpu swiftshader_indirect -no-boot-anim
```
> `-gpu swiftshader_indirect` 走软件渲染，老机器上比硬件加速更稳；嫌卡可去掉。

**方式三 · 一键脚本**
仓库根目录的 `启动模拟器.bat` 会依次：检查已有设备 → 没有就启动带窗口的 AVD → 等待开机完成 → 安装 APK → 启动 App。

### 3.2 常见坑：同一个 AVD 开了两个实例

| 进程 | 模式 | 端口 | 表现 |
|---|---|---|---|
| 实例 A | `-no-window` 无窗口 | 占住 5554/5555 | `adb devices` 能看到设备，但**没有任何窗口** |
| 实例 B | 带窗口 | 抢不到端口 | 启动失败 / 窗口一闪就没 |

**症状**：Android Studio 里点了 ▶ 看不到窗口，但命令行 `adb devices` 里却能看到设备。

**解决**：关掉无窗口实例（`adb emu kill`，或在任务管理器结束 `qemu-system-x86_64.exe`），带窗口的就能正常起来。

> 桌面已经开着模拟器窗口时，**不要再点 Device Manager 的 ▶**；要重启先关闭旧窗口。

### 3.3 确认设备就绪

```bash
adb devices -l          # 看到 emulator-5554  device 才算就绪
adb shell getprop sys.boot_completed   # 返回 1 = 系统已完全启动
```

| 状态 | 含义 | 处理 |
|---|---|---|
| `device` | ✅ 正常 | — |
| `offline` | ⏳ 还在启动 | 等 30 秒再看 |
| `unauthorized` | 未授权 | 模拟器里点「允许 USB 调试」 |
| 列表为空 | 没起来 / 被无窗口实例占用 | `adb emu kill` 后重开 |

## 四、真机调试（USB）

### 4.1 手机端

1. 设置 → 关于手机 → 连点「版本号」7 次开启开发者选项
2. 开发者选项 → 开启 **USB 调试**
3. USB 连接电脑，手机上选「允许 USB 调试」

```bash
adb devices -l    # 状态必须是 device，不是 unauthorized
```

### 4.2 建立端口转发（关键一步）

```bash
adb reverse tcp:8080 tcp:8080
```

然后在 App 设置里把服务器地址填成 `http://127.0.0.1:8080` —— 这是真机连本机服务端**最稳妥**的方式。

> **备选 · 局域网 IP**：手机与电脑连同一 Wi-Fi，服务端地址填 `http://<电脑局域网IP>:8080`。
> 注意 Windows 防火墙需放行 8080 端口，否则手机连不上。

### 4.3 模拟器 vs 真机 对照

| 场景 | 服务器地址 |
|---|---|
| Android 模拟器 | `http://10.0.2.2:8080`（默认已配置） |
| 真机 + `adb reverse` | `http://127.0.0.1:8080` ⭐ |
| 真机 + 局域网 | `http://<电脑IP>:8080` |

## 五、配套服务端

服务端提供每日健康贴士、在线急救库、AI 代理等增强能力。**不启动也不影响 App 使用**（所有数据都存本地）。

```bash
cd server
node server.js          # 或 Windows 双击 start.bat
```

**快速验证**：
```bash
curl http://127.0.0.1:8080/api/health
# {"status":"ok","service":"HeartSync Server","version":"1.0",...}
```

**一键自检**：双击 `server/自检.bat`，自动检查 Node.js、`.env` 配置、启动服务并探活。

**接口自动化测试**：
```bash
cd server && node test_api.js     # 44 个用例
```

> 测试会自行 spawn 一个服务端子进程。若 8080 端口已被占用，新进程启动失败会导致测试打到旧实例上、结果失真 —— **跑测试前先确认端口空闲**。

## 六、配置大模型 API Key

App 端：设置 → 大模型 AI 配置 → 填 Key → 保存。点击服务商 Chip 可自动切换 Base URL 与模型名。

| 服务商 | Base URL | 模型名 |
|---|---|---|
| 通义千问（有免费额度） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `kimi-k1-8k` |

服务端端：复制 `server/.env.example` 为 `server/.env` 并填入 Key。`.env` 已被 `.gitignore` 排除。

**未配置 Key 时**：App 会自动降级到服务端代理 → 服务端规则引擎 / 本地知识库兜底，功能不中断。

> **Key 的存放位置**：App 端的 Key 只存在手机本地 `SharedPreferences`，不随安装包分发，也不写进源码。

## 七、常用 adb 命令

```bash
# 安装 / 覆盖安装
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 启动（LoginActivity / MainActivity 是 exported=false，外部拉不起来，必须走 SplashActivity）
adb shell am start -n com.heartsync.app/.activity.SplashActivity

# 停止
adb shell am force-stop com.heartsync.app

# 崩溃日志（排查必查）
adb logcat -b crash

# 清空数据（回归测试前用，会删掉所有记录）
adb shell pm clear com.heartsync.app
```

### 截图与录屏

```bash
# 截图（Git Bash 下加 export MSYS_NO_PATHCONV=1 更保险）
adb exec-out screencap -p > shot.png

# 录屏（最多 15 秒，到时自动停）
adb shell screenrecord --time-limit 15 /sdcard/demo.mp4
adb pull /sdcard/demo.mp4 ./demo.mp4
```

> 想让状态栏时间统一显示成 9:41（截图更整洁）：
> `adb shell cmd statusbar set-time 09:41`

## 八、注入演示数据

`tools/seed_device_data.py` 可往本地库写入一周的睡眠 / 运动 / 情绪记录，并预估健康指数：

```bash
# 先把数据库从设备拉出来
adb shell "run-as com.heartsync.app cat /data/data/com.heartsync.app/databases/heartsync.db" > heartsync.db
python tools/seed_device_data.py heartsync.db
# 再推回去
adb push heartsync.db /data/data/com.heartsync.app/databases/  # 需要 root
```

## 九、排查速查表

| 症状 | 先查 | 处理 |
|---|---|---|
| 看不到模拟器窗口 | `adb devices` 有设备但没窗口 | 无窗口实例占端口 → `adb emu kill` 后重开 |
| 点了 ▶ 没反应 | Device Manager 里已有 AVD 在跑 | 先关掉旧的 |
| App 装不上 | `adb devices` 是不是 `offline` | 等开机完成 |
| App 打开闪退 | `adb logcat -b crash` | 看堆栈定位 |
| 列表一直是空的 | 数据被 `pm clear` 清了 | 重新录几条 |
| 首页贴士不更新 | 服务端没起 / 地址不对 | `curl http://127.0.0.1:8080/api/health` |
| AI 区提示"尚未配置 API Key" | Key 没配 | 设置页粘贴并保存 |
| 真机连不上服务端 | 防火墙 / 地址不对 | `adb reverse tcp:8080 tcp:8080` + 填 `127.0.0.1:8080` |
| 服务端测试结果异常 | 8080 被占用 | 先释放端口再跑 `test_api.js` |
